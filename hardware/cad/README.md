# Rhino CAD

[AA-Grad-Show-Speaker.3dm](AA-Grad-Show-Speaker.3dm) is Peter Neyra’s original Panel Speakers model in Rhino 8 format, using millimetres.

Start with the [CAD guide](../../docs/cad.md) for dimensions, saved studies and the difference between this design revision and the achieved prototype. [provenance.json](provenance.json) records the source hashes and geometry checks.
