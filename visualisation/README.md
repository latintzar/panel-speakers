# Native CAD visualisation

[native-cad-rear.blend](native-cad-rear.blend) contains the original hanging study’s cached mesh geometry and procedural birch, beech, cord and driver materials. Open it in Blender 4.5 or newer. The scene is configured for a two-thread CPU render and uses procedural materials.

[native-cad-rear.webp](native-cad-rear.webp) is the resulting reference image. It shows the saved CAD revision. The [Rhino model](../hardware/cad/AA-Grad-Show-Speaker.3dm) remains the editable design source; the [CAD guide](../docs/cad.md) explains the prototype revision.
